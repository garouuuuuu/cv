A PCI DSS–compliant module

I built the security of a PCI DSS–compliant payment module from scratch and implemented all of its security functionality myself, against a very strict deadline. The module was certified by a third-party assessor, whom I dealt with directly.

PCI DSS is the security standard for any system that stores, processes or transmits payment card data, and it spans 12 requirements, from network security controls to logging, testing and policy.
